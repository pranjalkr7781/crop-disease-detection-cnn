# Dataset

Leaf images from the PlantVillage dataset (Kaggle), 4 classes used:
- Potato___Late_blight
- Potato___healthy
- Tomato_Early_blight
- Tomato_Late_blight

Total: about 4,100 images, split 70/15/15 (train/validation/test).
The images are not included in this repository because of their size.
To reproduce, download the dataset and place each class folder here.
